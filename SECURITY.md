# Security Policy

## Reporting a vulnerability

Please do not disclose suspected vulnerabilities in a public issue.

Use GitHub's private **Report a vulnerability** flow for this repository. If that is unavailable, contact [legal@comitium.co](mailto:legal@comitium.co).

Include the affected page or component, reproduction steps, the security impact, and any supporting logs or screenshots that do not contain secrets or other users' data.

When researching a vulnerability, do not access data that does not belong to you, disrupt the service, move funds, or publish credentials and personal information.
